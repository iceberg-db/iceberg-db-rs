## Record a run

```powershell
cargo run -p idb-bench --release -- --config benchmarks/tpcds/bench.yaml `
  --notes "What you changed and why" `
  --change "patches/foo: short description"
```

Use `--no-history` to skip recording. `speedup_vs_duckdb` > 1 means iceberg-db-rs was faster.
